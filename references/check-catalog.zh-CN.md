# 检查项目录

> [English](check-catalog.md)

`sweep.py plan` 生成的每一行要你看什么，以及什么样的答案值得担心。不同系统版本、不同应用的菜单名称不一样，请描述你实际看到的内容，不要依赖固定路径。

## 账号层（`A-<账号>-...`）

| 键 | 看什么 | 值得担心的答案 |
|---|---|---|
| `sessions` | 账号的已登录设备列表和最近登录记录 | 当事人不认识的设备、浏览器或地点 |
| `recovery` | 找回邮箱和手机号 | 由别人掌控的地址或号码 |
| `second_factor` | 二次验证发到哪里 | 验证码发到当事人并不独占的手机或应用 |
| `forwarding` | 邮件转发地址、过滤规则、代理人 | 悄悄抄送或删除邮件的规则 |
| `linked_devices` | 聊天软件的“关联设备”／网页会话 | 当事人从没打开过的会话 |
| `app_access` | 被授权访问账号的第三方应用 | 有邮件或文件权限、却没人记得添加过的应用 |
| `sharing` | 位置、日历、相册、文件和家庭共享 | 还有人在接收实时位置或相册 |
| `password_known` | 有没有人设过、被告知过、看到过这个密码 | 有，尤其是被怀疑的那个人 |

## 设备层（`D-<设备>-...`）

**Android：** 设备管理器应用；无障碍服务；通知读取权限；哪些应用可以安装其他应用；工作资料或机构管理；完整应用列表（包括看起来像系统组件的名字）；VPN 配置和用户安装的证书；应用商店自带的恶意软件扫描。

**iPhone：** 系统自带的共享与访问权限检查（新版本中的“安全检查”）；描述文件与设备管理；登录 Apple 账户的设备；应用列表；VPN 和受信任证书；越狱迹象，例如出现意料之外的软件包管理类应用。

**Windows / Mac / Linux：** 远程控制和屏幕共享软件；开机或登录启动项、计划任务、服务；每个浏览器配置文件里的扩展；本地管理员账户；屏幕录制、完全磁盘访问等隐私授权；描述文件；SSH 授权密钥。

值得担心的答案：任何拥有广泛权限（读取通知、看屏幕、控制设备、读取所有文件）、而当事人叫不出名字或没装过的东西。

## 追踪层（`T-...`）

| 键 | 看什么 | 值得担心的答案 |
|---|---|---|
| `unknown_tracker_alert` | 手机对“随身陌生追踪器”的提醒 | 有提醒，尤其是反复出现 |
| `physical_look` | 包的夹层、外套口袋、车（轮拱、座椅下）、别人送的礼物 | 一个当事人没买过的小圆片或标签 |
| `map_sharing` | 地图、家庭、运动类应用里的实时位置共享 | 还有人在接收实时位置 |

## 特征层（`I-<设备>`）

用可信的取证工具，把手机备份或结构化采集数据，与已公开的已知间谍软件特征做离线比对。只有在监视者可能是 state_level 时才会列入计划。全程离线，备份私下保存，绝不访问特征里出现的任何地址，并阅读工具自己关于“哪些没能检查”的说明。命中只是需要专家确认的线索，不是最终答案；没命中只说明已加载的特征没有出现在读取到的记录里。

## 结果取值

- `none_seen`：看过，没有异常。
- `benign`：有点奇怪，但有无害解释；写下解释。
- `unexplained`：奇怪且暂时没人能解释；原样记录。
- `concerning`：强烈迹象表明他人有访问权；原样记录。
- `na`：这项检查没有执行。
